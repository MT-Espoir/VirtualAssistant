========================================
HƯỚNG DẪN NÂNG CẤP PHASE 1: THÊM KHẢ NĂNG TRÒ CHUYỆN
Voice Assistant Conversational AI Upgrade
========================================

TỔNG QUAN PHASE 1:
- Thời gian: 1-2 tuần
- Mục tiêu: Chuyển từ Command-Based sang Hybrid (Command + Conversation)
- Khó độ: Trung bình
- Yêu cầu: Kiến thức Python cơ bản, hiểu về NLP

========================================
BƯỚC 1: PHÂN TÍCH HỆ THỐNG HIỆN TẠI
========================================

1.1 XEM XÉT CẤU TRÚC HIỆN TẠI:
   - File main.py: Xử lý command-based
   - File main_gui.py: Giao diện người dùng
   - Thư mục nlp/: Chứa intent classifier và entity extractor
   - Thư mục actions/: Chứa các hành động cụ thể

1.2 NHẬN DIỆN HẠN CHẾ:
   - Chỉ có 6 intent cố định: app_control, system_control, web_search, greeting, goodbye, unknown
   - Phản hồi dựa trên template cứng nhắc
   - Không có memory/context cho cuộc trò chuyện
   - Không xử lý được câu hỏi mở, small talk

1.3 XÁC ĐỊNH ĐIỂM CHÈN:
   - Hàm execute_command() trong main.py và main_gui.py
   - Cần thêm logic phân biệt command vs conversation
   - Cần thêm conversation handler

========================================
BƯỚC 2: THIẾT KẾ KIẾN TRÚC MỚI
========================================

2.1 HYBRID APPROACH:
   - Giữ nguyên xử lý command cũ
   - Thêm conversation mode song song
   - Tự động phân biệt intent

2.2 THÊM INTENT MỚI:
   - "conversation": Trò chuyện tự nhiên
   - "question_answering": Trả lời câu hỏi
   - "small_talk": Chuyện phiếm
   - "help": Hướng dẫn sử dụng

2.3 CONTEXT MANAGEMENT:
   - Lưu trữ 5-10 câu hội thoại gần nhất
   - Theo dõi chủ đề đang nói
   - Nhận diện khi nào chuyển chủ đề

========================================
BƯỚC 3: THIẾT LẬP MÔI TRƯỜNG
========================================

3.1 CÀI ĐẶT OLLAMA (KHUYẾN NGHỊ):
   - Tải Ollama từ https://ollama.com/download/windows
   - Cài đặt theo hướng dẫn
   - Chạy lệnh: ollama run llama3:3b
   - Kiểm tra hoạt động: curl http://localhost:11434/api/generate

========================================
BƯỚC 4: TẠO MODULE CONVERSATION

4.1 TẠO FILE llm/conversation_engine.py:

   - Method generate_response()
   - Method update_context()
   - Method clear_context()

4.2 TẠO FILE llm/ollama_client.py:
   - Class OllamaClient

   - Method format_prompt()

4.3 TẠO FILE llm/pattern_matcher.py:

   - Vietnamese language specific patterns
   - Fallback responses

BƯỚC 5: MỞ RỘNG INTENT CLASSIFIER
========================================

5.1 CẬP NHẬT training_data/training_data.jsonl:
   - Thêm 50-100 ví dụ cho intent "conversation"
   - Thêm 30-50 ví dụ cho intent "question_answering"
   - Thêm 30-50 ví dụ cho intent "small_talk"

5.2 TRAINING EXAMPLES:
   Conversation:
   - "bạn thế nào"
   - "hôm nay trời đẹp nhỉ"
   - "kể cho tôi nghe về..."

   Question Answering:
   - "thời tiết hôm nay ra sao"
   - "mấy giờ rồi"
   - "ai là tổng thống Việt Nam"

5.3 RETRAIN MODEL:
   - Chạy lại training script
   - Kiểm tra độ chính xác
   - Fine-tune nếu cần

BƯỚC 6: TÍCH HỢP VÀO HỆ THỐNG CHÍNH
========================================

6.1 CẬP NHẬT main.py:
   - Import conversation modules
   - Thêm conversation_history list
   - Thêm current_context dict

6.2 CẬP NHẬT main_gui.py:

6.3 LOGIC PHÂN BIỆT:

========================================
BƯỚC 7: PATTERN MATCHING CƠ BẢN
========================================

7.1 COMMON PATTERNS:
   - Greeting: "xin chào", "hello", "hi"
   - Thanks: "cảm ơn", "thank you"
   - Weather: "thời tiết", "trời"
   - Time: "mấy giờ", "time"
   - Personal: "bạn là ai", "who are you"

7.2 CONTEXT PATTERNS:
   - Follow-up questions: "còn gì nữa", "what else"
   - Clarification: "ý bạn là gì", "what do you mean"
   - Topic change: "chuyện khác", "another topic"

7.3 FALLBACK RESPONSES:
   - "Điều đó nghe thú vị"
   - "Bạn có thể kể thêm không?"
   - "Tôi hiểu rồi"

========================================
BƯỚC 8: MEMORY & CONTEXT MANAGEMENT
========================================

8.1 CONVERSATION HISTORY:
   - Lưu trữ circular buffer (5-10 câu)
   - Format: [{"role": "user", "content": "...", "timestamp": "..."}]
   - Tự động xóa sau 30 phút không hoạt động

8.2 CONTEXT TRACKING:
   - current_topic: Chủ đề đang nói
   - user_preferences: Sở thích người dùng
   - last_command: Lệnh cuối cùng
   - conversation_mode: True/False

8.3 CONTEXT CLUES:
   - Nhận diện đại từ: "nó", "cái đó", "việc này"
   - Liên kết với context trước đó
   - Maintain topic coherence

========================================
TROUBLESHOOTING COMMON ISSUES
========================================

1. OLLAMA CONNECTION ERROR:
   - Check if Ollama service is running
   - Verify port 11434 is open
   - Try restart Ollama service

2. SLOW RESPONSE:
   - Reduce model size (3B → 1.5B)
   - Increase RAM allocation
   - Use GPU if available

3. INTENT CLASSIFICATION WRONG:
   - Add more training data
   - Retrain model
   - Check data quality

4. CONTEXT NOT WORKING:
   - Check conversation history storage
   - Verify context passing to LLM
   - Debug memory management

5. RESPONSE QUALITY POOR:
   - Adjust prompt engineering
   - Fine-tune temperature
   - Add response filtering
