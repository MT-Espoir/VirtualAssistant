HƯỚNG DẪN HIỆN THỰC TÍNH NĂNG DỰ ĐOÁN THỂ LOẠI NHẠC TỪ CẢM XÚC
=================================================================================

MỤC TIÊU:
Xây dựng hệ thống có thể dự đoán thể loại nhạc dựa trên các từ khóa cảm xúc mà người dùng 
mô tả (ví dụ: "nhẹ nhàng", "buồn", "nhộn nhịp", "sâu lắng", v.v.)

=================================================================================
PHẦN 1: THIẾT KẾ KIẾN TRÚC TỔNG QUAN
=================================================================================

1.1. CẤU TRÚC DỮ LIỆU CẦN THIẾT:
--------------------------------
- Emotion-to-Genre Mapping Dictionary: 
  + Key: từ khóa cảm xúc (string)
  + Value: danh sách thể loại nhạc có thể (list)
  + Confidence score cho mỗi mapping

- Genre Categories:
  + Classical, Pop, Rock, Jazz, Electronic, Hip-Hop, R&B, Country, 
    Folk, Ballad, Dance, Ambient, Blues, Reggae, etc.

- Emotion Keywords Database:
  + Positive: vui, hạnh phúc, phấn khích, năng động, sôi động
  + Negative: buồn, u sầu, melancholy, cô đơn, tuyệt vọng
  + Calm: nhẹ nhàng, thanh tịnh, thư giãn, yên bình, tĩnh lặng
  + Energetic: nhộn nhịp, mạnh mẽ, bùng nổ, sôi động
  + Romantic: lãng mạn, ngọt ngào, đắm đuối, tình cảm
  + Deep: sâu lắng, suy tư, triết lý, nội tâm

1.2. LUỒNG XỬ LÝ CHÍNH:
-----------------------
Input Text → Preprocessing → Emotion Detection → Genre Mapping → Confidence Scoring → Output

=================================================================================
PHẦN 2: HIỆN THỰC TỪNG BƯỚC
=================================================================================

BƯỚC 1: TẠO EMOTION-GENRE MAPPING DICTIONARY
--------------------------------------------
Nhiệm vụ: Tạo một dictionary mapping các từ khóa cảm xúc với thể loại nhạc

Gợi ý implementation:
- Tạo file JSON hoặc dictionary trong Python chứa mapping
- Mỗi emotion keyword có thể map tới nhiều genre với confidence score khác nhau
- Ví dụ: "nhẹ nhàng" → [("Classical", 0.8), ("Acoustic", 0.7), ("Ambient", 0.6)]

Cấu trúc đề xuất:
```
emotion_to_genre = {
    "nhẹ_nhàng": [("Classical", 0.8), ("Acoustic", 0.7), ("Ambient", 0.6)],
    "buồn": [("Ballad", 0.9), ("Blues", 0.7), ("Classical", 0.5)],
    "nhộn_nhịp": [("Pop", 0.8), ("Dance", 0.9), ("Electronic", 0.7)],
    "sâu_lắng": [("Jazz", 0.8), ("Classical", 0.7), ("Blues", 0.6)]
}
```

BƯỚC 2: PREPROCESSING VÀ NORMALIZATION
-------------------------------------
Nhiệm vụ: Chuẩn hóa input text để matching hiệu quả

Các task cần làm:
a) Text normalization:
   - Chuyển về lowercase
   - Loại bỏ dấu câu
   - Xử lý dấu tiếng Việt (có thể dùng unidecode)

b) Synonym handling:
   - Tạo synonym dictionary: "vui vẻ" = "hạnh phúc" = "phấn khích"
   - Expand input với các từ đồng nghĩa

c) Phrase detection:
   - Nhận diện các cụm từ: "nhẹ nhàng", "sâu lắng"
   - Xử lý multi-word expressions

BƯỚC 3: EMOTION DETECTION ALGORITHM
----------------------------------
Nhiệm vụ: Phát hiện các emotion keywords trong text

Thuật toán đề xuất:
a) Exact matching:
   - Tìm kiếm trực tiếp các emotion keywords
   - Sử dụng regex cho flexible matching

b) Fuzzy matching:
   - Xử lý typos và variations (dùng thư viện fuzzywuzzy)
   - Set threshold cho similarity score

c) Context analysis:
   - Xem xét từ ngữ xung quanh để tăng độ chính xác
   - Phát hiện negation ("không buồn" ≠ "buồn")

BƯỚC 4: GENRE PREDICTION ENGINE
------------------------------
Nhiệm vụ: Dự đoán thể loại nhạc từ detected emotions

Algorithm steps:
a) Collect all detected emotions with confidence scores
b) Map each emotion to potential genres
c) Aggregate scores for each genre
d) Apply weighting based on emotion strength
e) Return top N genres with confidence scores

Công thức tính score đề xuất:
```
Genre_Score = Σ(Emotion_Confidence × Mapping_Confidence × Context_Weight)
```

BƯỚC 5: CONFIDENCE SCORING SYSTEM
---------------------------------
Nhiệm vụ: Đánh giá độ tin cậy của prediction

Factors ảnh hưởng confidence:
- Số lượng emotion keywords detected
- Strength của từng emotion keyword
- Consistency giữa các emotions
- Text length và quality

BƯỚC 6: LEARNING MECHANISM (ADVANCED)
------------------------------------
Nhiệm vụ: Cải thiện accuracy theo thời gian

Implementation ideas:
a) User feedback collection:
   - Thu thập feedback về prediction accuracy
   - Lưu trữ correction data

b) Model adaptation:
   - Cập nhật confidence scores dựa trên feedback
   - Thêm new emotion-genre mappings

c) Personalization:
   - Học preference của từng user
   - Customize predictions cho individual users
